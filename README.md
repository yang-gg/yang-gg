**Featured Projects / 代表项目**

- [**Tamoxifen resistance in ER+ breast cancer (bulk RNA-seq)**](https://github.com/yang-gg/rnaseq-tamoxifen-resistance)
  End-to-end analysis of GSE111151: Galaxy (fastp, Salmon) for upstream processing, then DESeq2, edgeR, limma-voom and GSEA in R with a paired design across four cell lines. Identifies a shared resistance signature (loss of ER signalling, EMT) and reproduces the original study's lipid findings.
